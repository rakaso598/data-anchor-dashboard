## 2. 트러블슈팅 및 해결 내역

- **API Key 인증 관리**
  - 문제: .env가 아닌 웹 UI에서 입력/해제, localStorage/Context 동기화, fetcher에서 자동 적용이 불안정
  - 해결: useEffect, storage 이벤트 활용해 상태 동기화, 자물쇠 버튼 UX 개선, fetcher에서 항상 최신 값 반영

- **React key 중복 경고**
  - 문제: SWR로 받아온 레코드 목록에서 key 중복/누락 경고 발생
  - 해결: key={row.hash ?? `${row.version}-${row.createdAt}`}로 안전하게 처리

- **SSR/CSR 충돌**
  - 문제: app/layout.tsx에서 "use client"와 metadata 충돌, 클라이언트 전용 Provider 분리 필요
  - 해결: ClientProviders 컴포넌트로 분리, SSR/CSR 안전성 확보

- **상태 동기화**
  - 문제: 여러 탭에서 API Key 변경 시 동기화 문제
  - 해결: window.addEventListener('storage')로 동기화 처리

- **폼 검증/UX**
  - 문제: Zod+React Hook Form 연동 시 타입 오류 및 UX 미흡
  - 해결: zodResolver, 명확한 타입 선언, 에러 메시지/스낵바 UX 개선

- **문서화/가이드**
  - 문제: 구조/기술/가이드가 분산되어 이해 어려움
  - 해결: docs/에 구조, SWR vs fetch, UI 라이브러리 비교, Zod/React Hook Form 가이드 등 상세 문서화
